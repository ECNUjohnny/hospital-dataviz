# Hospital Geo-Data Visualization: Shanghai vs. Tokyo

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Click%20Here-success.svg)](https://ecnujohnny.github.io/hospital-dataviz)

This web application visualizes and compares the geographical distribution of hospitals in **Shanghai** and **Tokyo**. By mapping healthcare facilities, this project aims to provide an intuitive spatial understanding of medical resource allocation across two major Asian metropolises.

🔗 **Access the live website here:** [https://ecnujohnny.github.io/hospital-dataviz](https://ecnujohnny.github.io/hospital-dataviz)

---

## Features

The application provides multiple interactive utilities for users to explore the datasets effectively:

* **Overview Map:** A macroscopic view plotting all hospital locations across both cities, allowing users to zoom and pan to explore specific districts.
* **Heatmap Analysis:** Highlights the density of medical facilities, making it easy to identify healthcare hubs and resource-scarce areas at a glance.
* **Interactive Statistics:** Data-driven charts and metrics that break down the distribution patterns and provide deeper insights beyond just map coordinates.
